## Get Started in 3 Steps

You can go from zero to a running workflow in just a few minutes. Follow these steps to make your first successful API call.

<Steps>
  <Step title="Get Your API Key">
    Log in to your EcoRPA dashboard at [app.ecorpa.com](https://app.ecorpa.com), navigate to **Settings → API Keys**, and generate a new key. Keep it safe — you'll use it to authenticate every request.
  </Step>
  <Step title="Make Your First Call">
    Use your API key to authenticate and call the `/v1/workflows` endpoint. You'll receive a list of your existing workflows, confirming that your credentials are working correctly.
  </Step>
  <Step title="Build">
    With authentication in place, start creating workflows, managing tasks, and connecting integrations using the full EcoRPA API surface.
  </Step>
</Steps>
