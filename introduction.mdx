Las APIs de ECORPA te permiten **consultar**, **generar formularios** y **radicar afiliaciones** de seguridad social en Colombia. Te autenticas con una API Key y trabajas por solicitud: envías un lote, recibes un `IdSolicitud` y consultas el resultado.

## Servicios

| Servicio | Path | Scope |
| --- | --- | --- |
| [Consultas seguridad social](/consultas-seguridad-social) | `/v2/consulta/seguridad_social` | `consultas_seguridad_social` |
| [Consulta de antecedentes](/consulta-antecedentes) | `/v2/consulta/antecedentes` | `consulta_antecedentes` |
| [Formularios de afiliación](/formularios-afiliacion) | `/v2/formularios/afiliacion` | `formularios_afiliacion` |
| [Afiliaciones seguridad social](/afiliaciones-seguridad-social) | `/v2/afiliaciones/seguridad_social` | `afiliaciones_seguridad_social` |

## URL base

```text
https://apis.ecorpa.com/v2
```

## Flujo

<Steps>
  <Step title="Autenticar">
    Header `Authorization: Bearer ecorpa_key_…` con el scope del servicio.
  </Step>
  <Step title="Crear solicitud">
    `POST` con uno o varios registros. Respuesta con `IdSolicitud`.
  </Step>
  <Step title="Consultar resultado">
    `GET …/{IdSolicitud}` hasta que cada ítem termine (`procesado`, `error`, etc.).
  </Step>
</Steps>

## Formato de respuesta

Las respuestas van en **PascalCase**:

```json
{
  "Success": true,
  "Message": "Texto legible",
  "Data": {}
}
```
