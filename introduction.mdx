EcoRPA is a REST API platform built for developers and teams who need to automate repetitive processes, coordinate tasks across systems, and integrate third-party services without managing complex infrastructure. Whether you're a solo developer scripting internal tooling or an engineering team embedding automation into a product, EcoRPA gives you a consistent, well-documented API that scales with your needs.

## Key Features

EcoRPA is designed to cover the full automation lifecycle — from defining a workflow to receiving real-time event notifications when something changes.

## How It Works

The EcoRPA API follows a straightforward request-response model built on HTTPS. You authenticate with an API key, define your workflows and tasks as JSON resources, execute them via API calls, and receive results either synchronously or through webhook events.

<Steps>
  <Step title="Authenticate">
    Obtain an API key from your EcoRPA dashboard and include it as a Bearer token in the `Authorization` header of every request.
  </Step>
  <Step title="Create a Workflow">
    Send a `POST` request to `/v1/workflows` with a JSON body describing your workflow — its name, description, steps, and trigger conditions.
  </Step>
  <Step title="Execute Tasks">
    Trigger workflow executions manually via the API or let EcoRPA run them automatically based on your configured schedule or event triggers.
  </Step>
  <Step title="Receive Webhook Events">
    Configure a webhook endpoint on your server and subscribe to the events that matter to you. EcoRPA delivers real-time POST notifications whenever key state changes occur.
  </Step>
</Steps>

## Base URL

All API requests are made over HTTPS to the following base URL. Append the path for the specific endpoint you want to call.

```text
https://api.ecorpa.com/v1
```
