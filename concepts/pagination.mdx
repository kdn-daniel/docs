All list endpoints in EcoRPA return paginated results using cursor-based pagination. Rather than retrieving every resource at once, the API splits results into pages and provides a cursor value you can pass in subsequent requests to advance through the full result set. This approach is efficient for large datasets and remains stable even when records are added or removed between requests.

## Response Structure

Every list response includes a `data` array containing the resources for the current page and a `meta` object with pagination state. Use the `next_cursor` value to fetch the following page; when `next_cursor` is `null`, you have reached the last page.

```json
{
  "data": [ ... ],
  "meta": {
    "total": 150,
    "per_page": 20,
    "next_cursor": "cursor_abc123",
    "prev_cursor": null
  }
}
```

## Query Parameters

Use the following query parameters to control which page of results the API returns.

<ParamField query="per_page" type="integer" default="20">
  The number of records to include on each page. The minimum value is `1` and the maximum value is `100`. Requesting more records per page reduces the total number of requests needed to retrieve a full dataset.
</ParamField>

<ParamField query="cursor" type="string">
  An opaque cursor string returned in the `meta.next_cursor` or `meta.prev_cursor` field of a previous response. Pass this value to retrieve the page of results immediately after or before the current page.
</ParamField>

## Fetching All Pages

To retrieve every record from a list endpoint, loop through pages by passing the `next_cursor` from each response into the next request. Stop when `next_cursor` is `null`.

```python
import os
import requests

api_key = os.environ["ECORPA_API_KEY"]
base_url = "https://api.ecorpa.com/v1"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Accept": "application/json",
}

def fetch_all_workflows():
    all_workflows = []
    cursor = None

    while True:
        params = {"per_page": 100}
        if cursor:
            params["cursor"] = cursor

        response = requests.get(
            f"{base_url}/workflows",
            headers=headers,
            params=params,
        )
        response.raise_for_status()
        body = response.json()

        all_workflows.extend(body["data"])

        cursor = body["meta"].get("next_cursor")
        if not cursor:
            break

    return all_workflows

workflows = fetch_all_workflows()
print(f"Retrieved {len(workflows)} workflows.")
```

<Tip>
  Set `per_page=100` whenever you need to fetch a large number of records. Using the maximum page size minimizes the total number of HTTP requests your application makes, which reduces latency and helps you stay within the API rate limits.
</Tip>
