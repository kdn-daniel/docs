Con las APIs de ECORPA puedes **consultar**, **generar formularios** y **radicar afiliaciones** de seguridad social en Colombia. Te autenticas con una API Key y trabajas por solicitud: envías un lote, recibes un `IdSolicitud` y luego consultas el resultado.

## Productos

| Producto | Path | Scope |
| --- | --- | --- |
| Consulta seguridad social | `/v2/consulta/seguridad_social` | `consultas_seguridad_social` |
| Consulta antecedentes | `/v2/consulta/antecedentes` | `consulta_antecedentes` |
| Formularios de afiliación | `/v2/formularios/afiliacion` | `formularios_afiliacion` |
| Afiliaciones seguridad social | `/v2/afiliaciones/seguridad_social` | `afiliaciones_seguridad_social` |

Cada producto tendrá su propia guía en esta documentación.

## URL base

```text
https://apis.ecorpa.com/v2
```

## Cómo funciona

En casi todos los productos el flujo es el mismo:

<Steps>
  <Step title="Autentícate">
    Incluye tu key en el header: `Authorization: Bearer ecorpa_key_…`, con el scope del producto que vas a usar.
  </Step>
  <Step title="Crea la solicitud">
    Haz un `POST` con uno o varios registros. Si todo cuadra, te devolvemos un `IdSolicitud`.
  </Step>
  <Step title="Consulta el resultado">
    Con un `GET` a `…/{IdSolicitud}` revisas el avance hasta que cada ítem termine (`procesado`, `error`, etc.).
  </Step>
</Steps>

## Cómo respondemos

Las respuestas van en **PascalCase** y siempre traen este sobre:

```json
{
  "Success": true,
  "Message": "Texto legible",
  "Data": {}
}
```

Cuando quieras, sigue con [Autenticación](/authentication) para ver cómo armar el header y los scopes.
