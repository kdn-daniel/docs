This changelog tracks all notable changes to the EcoRPA API, including new endpoints, enhancements, bug fixes, and breaking changes. Review this page before upgrading your integration to understand what has changed between versions and whether any updates to your code are required.

<AccordionGroup>

  <Accordion title="v1.3.0 — January 2025">
    **New Features**

    - ✨ Added `POST /v1/webhooks/{id}/test` endpoint, which lets you send a test event to a registered webhook URL to verify your listener is working correctly.
    - ✨ Added a `search` query parameter to `GET /v1/workflows`, enabling you to filter workflows by name or description without retrieving the full list.

    **Bug Fixes**

    - 🐛 Fixed an issue where the pagination cursor returned `null` on the last page instead of indicating that no further pages exist. The `next_cursor` field now correctly omits itself when there are no more results.
  </Accordion>

  <Accordion title="v1.2.0 — November 2024">
    **New Features**

    - ✨ Added the Integrations resource with full CRUD support: `GET /v1/integrations`, `POST /v1/integrations`, and `DELETE /v1/integrations/{id}`. Use this resource to connect and manage third-party service integrations.
    - ✨ Added the `task.failed` webhook event type, so your application can react in real time whenever a task encounters an error during execution.

    **Improvements**

    - 🔧 Improved rate limit response headers to include `X-RateLimit-Reset`, giving you the exact Unix timestamp at which your rate limit window resets. This makes it easier to implement automatic retry logic.
  </Accordion>

  <Accordion title="v1.1.0 — September 2024">
    **New Features**

    - ✨ Added Tasks resource endpoints, including `GET /v1/tasks`, `POST /v1/tasks`, `GET /v1/tasks/{id}`, `PATCH /v1/tasks/{id}`, and `DELETE /v1/tasks/{id}`. You can now create and manage tasks directly via the API.
    - ✨ Added webhook signature verification using HMAC-SHA256. Every webhook delivery now includes an `X-EcoRPA-Signature` header so you can confirm that the payload originated from EcoRPA.

    **Improvements**

    - 🔧 Standardized the error response format across all endpoints. All error responses now include an `error.code` field alongside `error.message`, making it easier to handle specific error conditions programmatically.
  </Accordion>

  <Accordion title="v1.0.0 — July 2024">
    **Initial Release**

    - 🚀 Initial release of the EcoRPA REST API. This version establishes the foundational API surface for building workflow automation and task management integrations.
    - Includes the Workflows resource with endpoints to create, retrieve, update, and delete automation workflows.
    - Includes the Webhooks registration resource, enabling you to subscribe to real-time events from EcoRPA.
    - Authenticates all requests using API key Bearer tokens passed in the `Authorization` header.
  </Accordion>

</AccordionGroup>

<Note>
  To stay informed about new releases, follow the [EcoRPA GitHub repository](https://github.com/ecorpa) and enable release notifications. You can also check the **Changelog** section of your EcoRPA dashboard for a summary of recent updates.
</Note>
