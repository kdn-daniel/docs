Usa `Entidad: "afiliaciones_seguridad_social_ccf"` y `CodigoEntidad` de CCF en cada registro.

<Info>
  Canal, crear, reprocesar y GET están en [Afiliaciones seguridad social](/afiliaciones-seguridad-social).
</Info>

## Request

```bash
curl -sS -X POST "https://apis.ecorpa.com/v2/afiliaciones/seguridad_social" \
  -H "Authorization: Bearer ecorpa_key_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "AceptarTerminos": true,
    "Entidad": "afiliaciones_seguridad_social_ccf",
    "Canal": "plataforma",
    "FirmaTrabajador": true,
    "FirmaCliente": true,
    "RastrearCertificado": true,
    "Registros": [
      {
        "TipoDocumentoIdentificacion": "CC",
        "NumeroIdentificacion": "1020304050",
        "Nombres": "JUAN PEREZ",
        "Genero": "MAS",
        "CodigoNacionalidad": "170",
        "CodigoPaisNacimiento": "170",
        "FechaNacimiento": "11/05/1997",
        "CodigoDaneCiudadNacimiento": "11001",
        "FechaIngreso": "03/08/2026",
        "Afp": "PROTECCION S.A.",
        "Arl": "COLPATRIA",
        "Ibc": "1750905",
        "DireccionResidencia": "CALLE 1 # 2-3",
        "Celular": "3001234567",
        "CorreoElectronico": "ejemplo@correo.com",
        "CodigoDaneCiudadResidencia": "11001",

        "CodigoDaneCiudadLabor": "11001",
```
