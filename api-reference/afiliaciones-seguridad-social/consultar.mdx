---
title: "Consultar solicitud"
sidebarTitle: "Consultar solicitud"
description: "Estado, novedades y evidencias de una afiliación."
api: "GET /v2/afiliaciones/seguridad_social/{IdSolicitud}"
---

Devuelve el lote. Mientras `Estado` sea `procesando`, vuelve a consultar. `EstadoEntidad` es el estado ante la entidad (`radicado`, `certificado`, `devuelto`, …).

Scope: `afiliaciones_seguridad_social`. Guía: [Afiliaciones seguridad social](/afiliaciones-seguridad-social).

<ParamField path="IdSolicitud" type="string" required>
  UUID que devolvió el [POST](/api-reference/afiliaciones-seguridad-social/crear).
</ParamField>

<ResponseField name="Data.Registros[].Estado" type="string">
  `procesando`, `procesado` o `error`.
</ResponseField>

<ResponseField name="Data.Registros[].EstadoEntidad" type="string">
  Estado ante la entidad.
</ResponseField>

<ResponseField name="Data.Registros[].Novedades" type="object[]">
  Histórico del proceso. `Evidencia` solo si ese paso tiene archivo. Si una URL deja de funcionar, vuelve a llamar este GET.
</ResponseField>

<RequestExample>
```bash Request
curl -sS -X GET "https://apis.ecorpa.com/v2/afiliaciones/seguridad_social/657175d1-80dc-4f5a-98a3-debebc49bba5" \
  -H "Authorization: Bearer ecorpa_key_xxxxxxxx"
```
</RequestExample>
