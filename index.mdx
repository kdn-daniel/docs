## Por dónde empezar

<Steps>
  <Step title="Consigue tu API Key">
    Entra a [app.ecorpa.com](https://app.ecorpa.com), ve a **Configuración → API Keys** y genera una key con los scopes del producto que vas a consumir.
  </Step>
  <Step title="Lee Autenticación y Empezar">
    Revisa el header `Authorization: Bearer …` y el checklist de [Empezar](/quickstart) para validar que la key responde.
  </Step>
  <Step title="Integra el producto">
    Cuando estés listo, usa la URL base `https://apis.ecorpa.com/v2` y el endpoint del producto que necesites.
  </Step>
</Steps>
