---
title: "Consultar formulario de afiliación"
sidebarTitle: "Consultar solicitud"
description: "GET del estado y del PDF generado para un lote de formularios de afiliación EPS o CCF, a partir de su IdSolicitud, con datos por registro."
api: "GET /v2/formularios/afiliacion/{IdSolicitud}"
---

Devuelve el lote. Mientras un registro esté en `procesando`, vuelve a consultar. Cuando está `procesado`, `Formularios[]` trae las URL.

Scope: `formularios_afiliacion`.

<ParamField path="IdSolicitud" type="string" required>
  UUID que devolvió el POST de [crear](/api-reference/formularios-afiliacion/crear) o [actualizar](/api-reference/formularios-afiliacion/actualizar).
</ParamField>

<ResponseField name="Data.Registros[].Estado" type="string">
  `procesando`, `procesado` o `error`.
</ResponseField>

<ResponseField name="Data.Registros[].Formularios" type="object[]">
  PDF generados (`EPS` / `CCF`) con `Url`. Si una URL deja de funcionar, vuelve a llamar este GET.
</ResponseField>

<RequestExample>
```bash Request
curl -sS -X GET "https://apis.ecorpa.com/v2/formularios/afiliacion/c565a29b-2c59-440f-9b0f-b19e2f586b92" \
  -H "Authorization: Bearer ecorpa_key_xxxxxxxx"
```
</RequestExample>
