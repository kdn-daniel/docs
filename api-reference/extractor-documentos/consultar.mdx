---
title: "Consultar extracción de documento de identidad"
sidebarTitle: "Consultar extracción"
description: "GET de la extracción del documento de identidad: campos, códigos DANE, formato, caras y calidad."
api: "GET /v2/extractor-documentos/documento-identidad/{IdSolicitud}"
---

Devuelve la extracción. Mientras un documento esté en `procesando`, vuelve a consultar. El detalle está en [Documento de identidad](/extractor-documentos/documento-identidad).

Scope: `extractor_documentos`.

<ParamField path="IdSolicitud" type="string" required>
  UUID que devolvió el [POST](/api-reference/extractor-documentos/crear). Si no es un UUID válido, la ruta no existe.
</ParamField>

<ResponseField name="Data.Documentos[].Estado" type="string">
  `procesando`, `procesado` o `error`.
</ResponseField>

<ResponseField name="Data.Documentos[].Campos" type="object">
  Cada clave trae `Valor`, `Confianza` (0 a 100) y `Fuente`.

  `TipoIdentificacion`, `NumeroIdentificacion`, `PrimerNombre`, `SegundoNombre`, `PrimerApellido`, `SegundoApellido`, `FechaNacimiento`, `DepartamentoNacimiento`, `CiudadNacimiento`, `Genero`, `FechaExpedicion`, `CiudadExpedicion`.
</ResponseField>

<ResponseField name="Data.Documentos[].CodigosDane" type="object">
  Código DANE cuando se encuentra: `DepartamentoNacimiento`, `Nacimiento`, `Expedicion`. Si no se encuentra, la clave no viene.
</ResponseField>

<ResponseField name="Data.Documentos[].Caras" type="object">
  `CaraA` y `CaraB`. `true` si esa cara está en el PDF.
</ResponseField>

<ResponseField name="Data.Documentos[].Calidad" type="object">
  `Puntaje`, `Nivel` y `Problemas`.
</ResponseField>

<RequestExample>
```bash Request
curl -sS -X GET "https://apis.ecorpa.com/v2/extractor-documentos/documento-identidad/f76d9c31-813c-4346-b0ec-f94b9f25a01c" \
  -H "Authorization: Bearer ecorpa_key_xxxxxxxx"
```
</RequestExample>
