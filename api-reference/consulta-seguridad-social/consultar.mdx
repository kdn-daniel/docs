---
title: "Consultar solicitud"
sidebarTitle: "Consultar solicitud"
description: "Estado y resultado de una consulta de seguridad social."
api: "GET /v2/consulta/seguridad_social/{IdSolicitud}"
---

Devuelve el lote. Mientras un ítem esté en `procesando`, vuelve a consultar. El `Resultado` listo está en [ADRES](/consultas-seguridad-social/adres).

Scope: `consultas_seguridad_social`.

<ParamField path="IdSolicitud" type="string" required>
  UUID que devolvió el [POST](/api-reference/consulta-seguridad-social/crear). Si no es un UUID válido, la ruta no existe.
</ParamField>

<ResponseField name="Success" type="boolean">
  `true` si se recuperó la solicitud.
</ResponseField>

<ResponseField name="Data" type="object">
  <Expandable title="properties" defaultOpen="true">
    <ResponseField name="IdSolicitud" type="string">
      UUID de la solicitud.
    </ResponseField>
    <ResponseField name="Entidad" type="string">
      Fuente consultada.
    </ResponseField>
    <ResponseField name="Consultas" type="object[]">
      Ítems del lote.

      <Expandable title="ítem">
        <ResponseField name="Estado" type="string">
          `procesando` o `procesado`.
        </ResponseField>
        <ResponseField name="Resultado" type="object">
          Cuando está `procesado`. La forma depende de la entidad.
        </ResponseField>
        <ResponseField name="Evidencia" type="string">
          URL de respaldo, si existe. Si deja de funcionar, vuelve a llamar este GET.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl -sS -X GET "https://apis.ecorpa.com/v2/consulta/seguridad_social/bf009ced-f1dc-42a0-b173-60f20fe02bc3" \
  -H "Authorization: Bearer ecorpa_key_xxxxxxxx"
```
</RequestExample>
